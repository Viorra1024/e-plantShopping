# Paradise Nursery Shopping Application

## About the Project
**Paradise Nursery** is an online plant shop application built with React and Redux. It allows users to browse a variety of houseplants categorized by their features, view detailed information including images, descriptions, and prices, and manage their shopping cart seamlessly.

## Features
- Interactive Landing Page with a "Get Started" button.
- Product listing grouped into categories (Air Purifying, Aromatic, Low Maintenance).
- Dynamic Shopping Cart using Redux Toolkit (`addItem`, `removeItem`, `updateQuantity`).
- Real-time calculation of total items and total cost.
